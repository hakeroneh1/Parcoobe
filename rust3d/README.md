# Parcoobe 3D

3D-клиент Parcoobe — отдельная игра на **Rust + macroquad** (не мод для GameMaker).
Один exe, все ресурсы вкомпилированы внутрь.

## Что умеет

* **Два вида камеры** (`F5`): классический вид сбоку (как в оригинале) и **вид от первого лица**.
* В первом лице `W`/`S` — вперёд/назад вдоль уровня, `Space` — прыжок, направление взгляда — куда идёшь.
* **Переназначение любых клавиш** (`F1`), сохраняется рядом с exe в `parcoobe3d.cfg`.
* Уровни взяты из оригинальной игры (`source/rooms/*.json`): стены, шипы, батуты, двери, грибы.
  Дверь в конце уровня переключает на следующий.
* Физика — та же 2D-физика оригинала (AABB, гравитация, прыжок), но отрисовка объёмная:
  стены/пол/потолок — текстурированные квады, уровень превращён в коридор.

## Сборка

```bash
cargo build --release                                   # Linux
cargo build --release --target x86_64-pc-windows-gnu    # Windows (нужен mingw-w64)
```

Windows-бинарник получается один файл `parcoobe3d.exe` (~1 МБ), рядом ничего не нужно
(конфиг `parcoobe3d.cfg` создаётся при первом изменении настроек).

Уровни пересобираются из данных игры:

```bash
python3 rust3d/bake_levels.py     # source/rooms/*.json -> rust3d/assets/levels.json
```

## Управление по умолчанию

| Действие | Клавиша |
|---|---|
| Влево / вправо (вид сбоку) | `A` / `D` |
| Вперёд / назад (первое лицо) | `W` / `S` |
| Прыжок | `Space` |
| Смена камеры | `F5` |
| Настройка клавиш | `F1` |
| Пауза/меню, выход | `Esc` |

## Ограничения

* Это не порт GameMaker-логики целиком: перенесены движение, смерть от шипов, батуты и двери.
  Враги (грибы) пока только отрисовываются, без урона.
* Уровни остаются 2D-схемой — «3D» это объёмная отрисовка того же геймплея (2.5D), а не
  переделанные трёхмерные уровни с моделями.
