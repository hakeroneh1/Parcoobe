# Исходник Parcoobe

Декомпилированный проект игры `Parcoob` / `Parcoobe` (GameMaker Studio 2, сборка 15.08.2022, alpha 0.0.11).
Получено из `data.win` через UndertaleModTool CLI — см. `../декомпилятор/README.md`.

## Структура

```
objects/<объект>/<событие>.gml   код объектов по событиям
scripts/<скрипт>.gml             глобальные скрипты (в т.ч. библиотека таймеров timer_*)
rooms/<комната>.json             размеры, цвет фона, слои и все инстансы с координатами
sprites/<имя>_<кадр>.png         кадры спрайтов
textures/Texture <n>.png         текстурные страницы (атласы), из которых нарезаны спрайты
sounds/                          музыка (music_1..4.ogg) и встроенные звуки (mJump, mDamage)
datafiles/                       splash.png и шрифт StayPixelRegular
metadata/                        JSON-описания всех ресурсов
strings.txt                      все строки из data.win
```

## Метаданные

| Файл | Что внутри |
|---|---|
| `metadata/general.json` | имя проекта, runtime, размеры окна, порядок комнат, счётчики ресурсов |
| `metadata/objects.json` | объекты: спрайт, родитель, флаги, события и их code entries |
| `metadata/sprites.json` | спрайты: размеры, origin, маргины, кадры и их области в атласе |
| `metadata/rooms` → `rooms/*.json` | комнаты: размеры, слои, инстансы (объект, x, y, масштаб, поворот) |
| `metadata/sounds.json` | звуки: тип, файл, громкость, встроенные данные |
| `metadata/fonts.json` | шрифты: размер, диапазон, число глифов |
| `metadata/paths.json` | пути и их точки |
| `metadata/variables.json` | все переменные байткода (имя, тип инстанса, id) |
| `metadata/functions.json` | все функции, вызываемые в байткоде |
| `metadata/texture_page_items.json` | нарезка атласов: какие прямоугольники куда попали |

## Что важно знать

* События объектов: `Create_0`, `Step_0`, `Draw_0`, `PreCreate_0`, `Collision_with_<объект>`;
  числа после имени события — подтип события GameMaker (для `Step_0` — обычный шаг,
  `Draw_0` — обычная отрисовка, `Draw_64` — GUI и т.д.).
* Имена ассетов — оригинальные (как в проекте автора): `oPlayer`, `sWall`, `lvl_1`, `timer_create`.
* Имена локальных переменных и точная структура выражений восстановлены декомпилятором эвристически,
  поэтому это не побайтовая копия авторских `.gml`, а эквивалентный по логике код.
* Файлов проекта `.yy`/`.yyp` в `data.win` нет — их пришлось бы восстанавливать отдельно.
